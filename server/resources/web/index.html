Shor swarm

Every browser on this page simulates shots of Shor's algorithm and sends back what it measured. The server collects them, recovers a period with continued fractions, and factors the semiprime. Then it moves on to a bigger one.

This is a classical simulation, not a quantum computer. Each shot runs Scotty's IterativeShor on a state vector of 2^(L+1) amplitudes, so the work grows exponentially with the size of the number; a laptop factors these numbers instantly by classical means. The bases are random, bases sharing a factor with N are skipped, and the server keeps a factorisation only if its period and its factors check out, so nothing here is compiled with the answer and a wrong report cannot produce a wrong result.
